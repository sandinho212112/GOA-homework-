Git არის ვერსიების კონტროლის სისტემა, რომელიც საშუალებას აძლევს პროგრამისტებს და გუნდებს მართონ და აკონტროლონ კოდის ცვლილებები. Git-ის საშუალებით შესაძლებელია პროექტის ისტორიის შენახვა, ცვლილებების ტრეკინგი და თანამშრომლობა სხვა დეველოპერებთან.
GitHub არის პლატფორმა, რომელიც იყენებს Git-ს და საშუალებას აძლევს მომხმარებლებს ატვირთონ თავიანთი Git რეპოზიტორები, გაუზიარონ კოდი და თანამშრომლონ სხვა დეველოპერებთან. GitHub ასევე უზრუნველყოფს დამატებით ფუნქციებს, როგორიცაა პრობლემების ტრეკინგი, ვიქტორინები და პროექტების მართვა.
git init - ახდენს ახალი Git საცავის ინიციალიზებას მიმდინარე დირექტორიაში.
git commit -m "commit message" - ახორციელებს ეტაპობრივ ცვლილებებს საცავში აღწერილობითი გზავნილით.
git push - ატვირთავს ლოკალურ ვალდებულებებს დისტანციურ საცავში, განაახლებს მას თქვენი ცვლილებებით.
